<objective>
Make quiz blocks non-revealing: answering an MCQ or True/False question locks the answer in silently — no green/red state, no "✓ Nailed it!" / "✗ Not quite — give it another go!", no per-option feedback, no "Try again". The learner advances freely. At module end, a single final score (percent + X of Y correct) is shown and is what drives pass/fail and the SCORM completion status.

Purpose: The current per-question reveal + retry loop turns every quiz into a guess-until-right exercise, which makes the reported score meaningless and gates the learner on each question instead of on overall performance.
Output: One unified quiz runtime in `scormExport.ts` (used by both the Learner Preview iframe and the exported SCORM package), a module-wide score in the completion modal, and authoring UI with the now-dead controls removed.
</objective>
