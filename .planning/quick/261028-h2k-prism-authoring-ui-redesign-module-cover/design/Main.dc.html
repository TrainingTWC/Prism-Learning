Handling customer requests

Learn how to respond to access, correction and deletion requests within the legal window.

The 30-day rule

Every request must receive a complete response within 30 calendar days of receipt. The clock starts the moment the request reaches any employee — not when it lands with the privacy team.

Verify, then log

Confirm the requester's identity using two data points you already hold. Then open a ticket tagged DSAR so the deadline is tracked automatically.

Tip
Never ask for more ID than you need. Over-collecting during verification is itself a privacy risk.
