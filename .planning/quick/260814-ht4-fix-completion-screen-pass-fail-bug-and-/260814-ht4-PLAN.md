<objective>
Fix the module completion screen so it shows fail-state copy whenever the learner scored below the pass score, and let authors write their own completion copy.

Two concrete defects today:
1. `buildLessonPage`'s `showComplete()` (`apps/web/src/lib/scormExport.ts:1536`) only swaps to pass/fail copy when `crit==='passed'`, so a `'completed'`-criteria module says "You crushed it!" at 0%.
2. `buildPreviewHtml`'s completion card (`scormExport.ts:1731-1742`) has **zero** pass/fail wiring — no `data-pass-*`/`data-fail-*` attributes, no `data-prism-complete-icon`, and its finish handler (`scormExport.ts:1787-1806`) never touches the title/body. `PreviewPage.tsx:185` also calls `buildPreviewHtml` with **no options**, so preview always assumes `passingScore: 80, completionCriteria: 'completed'`. This is what the user's screenshot shows.

Purpose: preview and exported SCORM must agree, and the copy must be the author's, not ours.
Output: persisted per-module completion settings, one shared completion-card renderer used by both builders, authoring UI in the export dialog.
</objective>
